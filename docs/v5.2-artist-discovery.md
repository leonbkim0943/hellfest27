# V5.2 — Artist discovery

Status: preparation; no production UI or sync changes in this phase.
Baseline: V5.1.1 (11f337477cb6b4f60e5aa277156dc3028051d49e).

## Data inventory
The completed 306-artist audit (GitHub Actions run 45925093142, artifact link-audit) contains 171 selected MusicBrainz IDs, 146 selected IDs with country metadata, 165 artists with album-title lists, and 16 MusicBrainz request errors. Selection is an automated candidate, not proof of identity. The current app contains 153 flags; reconcile with independently identified artists before expanding. Existing direct links (176 Spotify, 149 YouTube Music) remain as-is unless an identity error is verified.

## UI
- Keep the existing collapsible category and compact artist rows; do not add height to the collapsed row.
- Preserve A (no flag) and B (flag before name). Missing country is omitted.
- In the existing artist detail toggle: origin, formation year if established, one or two original Korean sentences on style, three entry tracks, up to two representative albums, existing personal memo.
- Keep listen/favorite/priority and artist music links outside the detail.
- No band photography in the first release; it adds licensing and mobile payload work.
- Song links use search for verified title + artist until a track-level URL is independently verified. Distinguish search from direct.
- No external lookup from a visitor browser. Publish curated static JSON; missing fields are omitted.

## Data contract
Separate public artist metadata from personal plan state. Key by exact existing artist name (the localStorage and Apps Script identifiers must not change). Proposed fields: musicbrainzId, countryCode, formationYear, descriptionKo, tracks[{title,sp?,yt?,sources[]}], albums[{title,year?,sources[]}], sources[], reviewStatus. Fields optional except exact name; missing values are not generated.
- Band origin, not member nationality or current residence.
- Distinguish release list from representative album recommendations. Do not label a random track as popular.
- For entry tracks prioritize corroborated artist discography, official releases and established popularity evidence when available; otherwise curate with a clearly labelled editorial recommendation.
- Match by ID and corroborating album/artist identity; review namesakes separately.
- Do not scrape images or reproduce external biographies.

## Work sequence
1. Extract existing verified/candidate identifiers and albums from the audit artifact; review identity and flags.
2. Pilot S/A/B acts (99 total), prioritize actual entry songs, verify titles, write original Korean descriptions.
3. Validate and integrate detail UI; extend to other 207 acts with explicit coverage counts.
4. Test mobile and desktop, accordion state, search/filter, memo, sync, previous backups and all 306 keys unchanged.
5. Publish only reviewed records; missing metadata remains unavailable rather than guessed.

## Non-goals
No changes to Apps Script, access PIN, synchronization schema, lineup dates, personal records, or link audit coverage. No unverified national flags or invented song/album titles.
